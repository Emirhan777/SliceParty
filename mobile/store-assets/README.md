# App Store screenshots

Four unedited native iPhone screenshots, captured from the standalone Release simulator app on iPhone 17 Pro Max. Each image is a 1320 x 2868 RGB PNG.

Capture build: https://expo.dev/accounts/emirhansimsek_lightning/projects/slice-party/builds/f880d130-a38e-4135-9839-2ec9dbffc8bf

The Maestro flow in `.maestro/store-screenshots.yml` captures the home screen, room creation, an actual shared room link, and TV instructions. The room link shown is temporary and expires after ten minutes. These are native screenshots, not browser renders or generated mockups.
